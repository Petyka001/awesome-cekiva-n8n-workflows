# 03 · AI Video Generation (Gemini Omni 1.1 Flash) → CEKIVA

> Every day an AI invents a short-video idea and prompt, CEKIVA generates the video with Gemini Omni 1.1 Flash and publishes it to TikTok, YouTube, Instagram and Facebook Reels: no video vendor, no file host, no per-network nodes.

---

## 1. Who is this workflow for?
- **Target Audience:** Solo creators and small brands that post short videos every day.
- **Experience Level:** Intermediate n8n user (AI agents and a polling loop).

## 2. What problem does it solve?
- **The Manual Pain:** A daily video pipeline normally chains a video-generation vendor (with its own key and an API that can disappear: Google retires the Veo 3.1 preview models on 2026-10-22), a place to host the file, a long fixed wait, and one publishing node per network, each with its own token.
- **The Automated Solution:** CEKIVA does both halves: `POST /v1/generate-video` creates the clip (Gemini Omni 1.1 Flash), a poll loop waits for it, and **one `POST /v1/posts` per network** publishes the CEKIVA-hosted file. A failed or stuck job stops the run before anything is posted, and CEKIVA refunds a failed video.

## 3. What do you need? (Prerequisites)
- **Core Platform:** n8n instance (self-hosted or Cloud)
- **Distribution API:** CEKIVA account and API key (`Authorization: Bearer <API_KEY>`, created under *Settings → API keys*). Connect your social accounts once in CEKIVA.
- **External Services & Credentials:** OpenAI API key (GPT-4.1 writes the idea and the video prompt).
- **Setup guide:** credentials, the video options and the platforms are in [SETUP.md](SETUP.md).
- **Technical Skills:** Basic understanding of importing n8n JSON and setting up credentials.

## 5. What you'll get (End-to-End Delivery)
- **Input Data:** Nothing: a daily schedule starts it (you can also run it by hand).
- **Automated Processing:** Idea and caption by AI, a video prompt, video generation by CEKIVA, a 30-second status poll with a cap of about 15 minutes, then one post per network.
- **Final Output:** A new vertical video live on TikTok, YouTube, Instagram and Facebook Reels each day, with a result row per network.
- **Your Remaining Task:** Set the niche in the idea prompt, watch the first runs, and decide whether TikTok should carry the *AI-generated* label (off by default).

## 6. A Real-World Example
- **Step 1: Input:**  
  Schedule trigger fires at 09:00. The idea agent returns: `A lighthouse keeper explains tide tables to a hand-puppet crab` with a caption and hashtags.
- **Step 2: Processing:**  
  The prompt agent expands it into a scene description; **CEKIVA: start video** sends `{"quality":"720p","duration_seconds":8,"aspect_ratio":"9:16"}`; after a few polls the status is `completed` and returns a CEKIVA-hosted `video_url`; four `POST /v1/posts` requests follow (`tiktok`, `youtube`, `instagram`, `facebook_reels`).
- **Step 3: Delivered Result:**  
  An 8-second vertical clip appears on the four channels with the AI-written caption. If the credits run out, the affected rows show `INSUFFICIENT_CREDITS` and the workflow reports it. *(Illustrative; every run produces a new idea.)*
